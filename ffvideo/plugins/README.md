# Plugin bundles

`codex/` and `claude/` here are source manifest/MCP templates. Install the generated **`dist/plugins/codex/`** or **`dist/plugins/claude/`** root after building, rather than a source template. Each generated 0.2.0 plugin contains its own skill, `runtime/package.json`, server bundle, web player, five voiced examples, 20 scenario templates, four local graphic fixtures, GSAP runtime and notices. The built MCP configuration launches `node` against its installed plugin root (`${PLUGIN_ROOT}` in Codex and `${CLAUDE_PLUGIN_ROOT}` in Claude). It requires Node.js 22 or newer on the host; it needs no global `ffvideo` command, published npm package or editing-plugin installation.

All runtime paths stay inside the plugin root, so copying one built plugin into a new host cache preserves its dependencies. Read `templates/README.md` and `templates/catalog.json` within the built plugin for Chinese descriptions, fields and complete examples. The registry is embedded in the server bundle, while the SVG, Canvas, Markdown and limited Lottie fixtures are also shipped in `runtime/dist/templates/media/`; they do not depend on the source checkout or remote URLs. These are controlled presets, not a general external-file importer. Use `list_draft_templates`, `get_draft_template` and `instantiate_draft_template` to select, copy and fill a template; use `create_template_draft` or `reuse_draft` to produce a separate voiced draft.

The default feed data directory is separate from the read-only installation. To use an isolated data directory or native Channels, generate an explicit host configuration with a path to that bundled executable. The `check-package.mjs` script copies each built plugin into a temporary directory, launches its MCP server and checks all 20 template copies/fills, local fixtures, player resources and real sample audio without installing into the user's host configuration.

The Claude manifest can also serve as a starting point for compatible CodeBuddy plugin packaging; host installation still needs verification. Channels are deliberately not enabled by a bundled plugin. Use the explicit host configuration/launch steps in `../hosts/README.md` when testing native push. WorkBuddy has its own connector metadata conventions, so a Claude manifest is not a WorkBuddy connector submission.

No template installs itself, writes user-home configuration or changes host approval settings.
