# ffvideo 制作系统：按内容创作文字和镜头

用户搜索的内容是随机的，话题决定文案与取材。本地素材库存只在相关时帮助减少重复下载，不能作为创作的前提，也不能让用户话题迁就库存。

## 文字编排

模型在一次创作调用中同时写完整旁白、镜头设计和 `design.typography`。每组文字有自己的内容目的、出现时机、位置、对齐、字距、行距与动画；每行可以混合字号、字体、颜色、实心字、空心字、下划线或局部色块。同一行按实际字形宽度和共同基线排版。

组合关系来自内容：问题与答案、概念对比、数字与单位、主张与证据、标题与解释。没有固定的整片标题栏或两张文字卡片；也不规定每条作品都按同一种三行标题排列。重点是主次、留白、阅读顺序与节奏，不能用换色和装饰数量替代质量。

字幕始终覆盖完整旁白。`captionKeywords` 指定真实旁白中的关键词，只强调短语，保留句子的其余文字，避免整句变色或靠标题替代字幕。当前字幕时间仍按旁白文本长度分配，不承诺逐字语音对齐。

## 本机快速路径

1. 一轮模型调用生成旁白、镜头和文字编排；模板只是可选的初始化参考。
2. 相关素材先查缓存与许可库存，缺失时按话题检索互联网素材；本机配音与取材并行。
3. 本机隔离的 Chrome/Chromium 使用安装字体测量、排版并一次生成透明文字 PNG。过密或超出安全区的排版会明确失败，不截掉文字。
4. 文字 PNG 作为普通原生图片层进入时间轴，动画使用原生关键帧。播放、拖动和导出无需逐帧执行 HTML，也没有增加生成式图片服务或二次审片调用。
5. 一条完成就发布，话题页继续按播放位置补足后面三条；不自动用模型翻做全部历史作品。

## 复用与原创性的边界

复用的是相关素材、字体、排版、裁切、关键帧与合成能力。完整作品的结构、画面重心、文字关系和节奏必须按内容重新组织。程序拒绝缺失设计、整片固定双卡片、同话题重复结构，以及只换字、换素材、换色或挪动几像素的复制。

这些检查只能守住结构与可读性底线，不能替代审美验收。精确示范需要准确对应的画面，库存标签匹配也不等于视觉理解。本轮文字改造不承诺所有题材的素材都准确、每条作品都达到同一审美水平，或固定的端到端生成秒数。
